🏗️ Classes & Objects

CORE CONCEPT

What are Classes?

Classes are blueprints for creating objects. They define attributes (data) and methods (functions) that objects will have.

🚗 Car Analogy

Class = Car blueprint/design plans from the manufacturer (e.g., "Toyota Camry 2024 design")

Object = The actual car you drive (your specific red Camry with VIN #12345)

Attributes = The car's properties (color, mileage, fuel level)

Methods = Actions the car can do (accelerate(), brake(), turn())

⚙️ C++ Equivalent

Python classes are similar to C++ classes, but Python is more flexible and doesn't require explicit access modifiers.

// C++ Version class Car { public: static int wheels = 4; // Class attribute // Constructor Car(string b, string c) : brand(b), color(c), speed(0) {} // Member function string accelerate(int amount) { speed += amount; return "Now going " + to_string(speed) + " mph"; } private: string brand; // Instance attributes string color; int speed; };

Key Differences:

  • Python: No explicit public/private (uses _ convention)
  • Python: Constructor is __init__() vs C++ constructor with class name
  • Python: self parameter explicit, C++ uses implicit 'this' pointer
  • Python: Dynamic typing, C++ requires type declarations
class Car: # Class attribute (shared by all instances) wheels = 4 # Constructor - initializes object def __init__(self, brand, color): # Instance attributes (unique to each object) self.brand = brand self.color = color self.speed = 0 # Instance method def accelerate(self, amount): self.speed += amount return f"Now going {self.speed} mph" # String representation def __str__(self): return f"{self.color} {self.brand}" # Creating objects (instances) my_car = Car("Toyota", "red") your_car = Car("Honda", "blue") print(my_car.accelerate(30)) # Now going 30 mph

Key Components

__init__ (Constructor)

Special method that runs when creating a new object. Initializes attributes.

self

Refers to the current instance. Required as first parameter in instance methods.

Instance Attributes

Data unique to each object (self.brand, self.color)

Class Attributes

Data shared by all instances (wheels = 4)

Inheritance

ADVANCED
class ElectricCar(Car): # Inherits from Car def __init__(self, brand, color, battery_size): super().__init__(brand, color) # Call parent constructor self.battery_size = battery_size # Method overriding def accelerate(self, amount): self.speed += amount * 1.5 # Electric cars accelerate faster! return f"⚡ Smoothly at {self.speed} mph" tesla = ElectricCar("Tesla", "white", 100)

⚡ Functions & Methods

CORE CONCEPT

🚗 Car Analogy

Function = A tool in your garage (like a tire pump) - standalone, can work on any car

Method = Built-in car function (like cruise control) - tied to that specific car

Parameters = Input (gas pedal pressure, steering wheel angle)

Return value = Output (new speed, new direction)

Regular Functions

def greet(name, greeting="Hello"): # Default parameter """This is a docstring - describes the function""" return f"{greeting}, {name}!" # Calling functions print(greet("Alice")) # Hello, Alice! print(greet("Bob", "Hi")) # Hi, Bob! print(greet(name="Eve", greeting="Hey")) # Keyword args

⚙️ C++ Equivalent

// C++ Version (Default Parameters) string greet(string name, string greeting = "Hello") { return greeting + ", " + name + "!"; } // Calling cout << greet("Alice"); // Hello, Alice! cout << greet("Bob", "Hi"); // Hi, Bob! // Note: C++ doesn't have keyword arguments natively

*args and **kwargs

ADVANCED
# *args - variable number of positional arguments def sum_all(*numbers): return sum(numbers) print(sum_all(1, 2, 3)) # 6 print(sum_all(1, 2, 3, 4, 5)) # 15 # **kwargs - variable number of keyword arguments def print_info(**info): for key, value in info.items(): print(f"{key}: {value}") print_info(name="Alice", age=25, city="Dallas")

🚗 Car Analogy

*args = Variable trunk space - fit any number of bags (1 bag, 5 bags, 10 bags)

**kwargs = Customizable dashboard - add any labeled controls you want (temp: 72, radio: FM, seat: heated)

⚙️ C++ Equivalent

// C++ uses variadic templates or initializer_list template<typename... Args> auto sum_all(Args... numbers) { return (numbers + ...); // Fold expression (C++17) } // Or using initializer_list int sum_all(initializer_list<int> numbers) { int total = 0; for (int n : numbers) total += n; return total; } // For **kwargs, C++ doesn't have native support // Would use std::map or similar

Lambda Functions (Anonymous)

# Single line functions square = lambda x: x ** 2 add = lambda x, y: x + y print(square(5)) # 25 print(add(3, 4)) # 7 # Common use with map, filter numbers = [1, 2, 3, 4, 5] squared = list(map(lambda x: x**2, numbers)) even = list(filter(lambda x: x % 2 == 0, numbers))

🚗 Car Analogy

Lambda = Quick roadside fix with duct tape - fast, temporary, no need to visit a full garage

Example: Instead of driving to a car wash (full function), use a spray bottle (lambda) for a quick spot clean

⚙️ C++ Equivalent

// C++ Lambda Functions (C++11+) auto square = [](int x) { return x * x; }; auto add = [](int x, int y) { return x + y; }; cout << square(5); // 25 cout << add(3, 4); // 7 // With algorithms vector<int> numbers = {1, 2, 3, 4, 5}; transform(numbers.begin(), numbers.end(), numbers.begin(), [](int x) { return x * x; });

Lists (Mutable, Ordered)

fruits = ["apple", "banana", "cherry"] # Common operations fruits.append("date") # Add to end fruits.insert(1, "avocado") # Insert at index fruits.remove("banana") # Remove by value popped = fruits.pop() # Remove and return last item fruits.sort() # Sort in place fruits.reverse() # Reverse in place # Slicing print(fruits[1:3]) # Items 1 and 2 print(fruits[::-1]) # Reverse the list # List comprehension squares = [x**2 for x in range(10)] even_squares = [x**2 for x in range(10) if x % 2 == 0]

⚙️ C++ Equivalent

// C++ vector (dynamic array) #include vector fruits = {"apple", "banana", "cherry"}; // Common operations fruits.push_back("date"); // Add to end fruits.insert(fruits.begin()+1, "avocado"); // Insert at index fruits.erase(remove(fruits.begin(), fruits.end(), "banana"), fruits.end()); fruits.pop_back(); // Remove last sort(fruits.begin(), fruits.end()); // Sort reverse(fruits.begin(), fruits.end()); // Reverse // Slicing not native - use iterators or copy vector subset(fruits.begin()+1, fruits.begin()+3);

Tuples (Immutable, Ordered)

coordinates = (10, 20) person = ("Alice", 25, "Dallas") # Unpacking x, y = coordinates name, age, city = person # Cannot modify tuples! # coordinates[0] = 15 # This would cause an error

⚙️ C++ Equivalent

// C++ tuple (C++11+) or std::pair #include tuple<int, int> coordinates(10, 20); tupleint, string> person("Alice", 25, "Dallas"); // Unpacking (C++17 structured bindings) auto [x, y] = coordinates; auto [name, age, city] = person; // Or use std::pair for 2 elements pair<int, int> coords(10, 20); int x = coords.first; int y = coords.second;

Dictionaries (Key-Value Pairs)

student = { "name": "Alice", "age": 22, "courses": ["FTEC 6V97", "CS 6301"] } # Accessing values print(student["name"]) # Alice print(student.get("gpa", 0.0)) # Safe access with default # Adding/modifying student["gpa"] = 3.8 # Iterating for key, value in student.items(): print(f"{key}: {value}") # Dictionary comprehension squared = {x: x**2 for x in range(6)}

🚗 Car Analogy

Like a car's feature lookup: key="heated_seats" → value=True, key="sunroof" → value=False

VIN lookup system: VIN (key) → Car details (value)

⚙️ C++ Equivalent

// C++ std::map (ordered) or std::unordered_map (hash table) #include #include mapint> student; student["age"] = 22; student["gpa"] = 3; // Accessing values cout << student["age"]; // 22 int gpa = student.count("gpa") ? student["gpa"] : 0; // Iterating for (const auto& [key, value] : student) { cout << key << ": " << value << endl; } // unordered_map is faster (O(1) vs O(log n)) unordered_mapint> fast_student;

Sets (Unique, Unordered)

numbers = {1, 2, 3, 4, 5} letters = set(["a", "b", "c", "a"]) # Duplicates removed # Set operations set_a = {1, 2, 3} set_b = {3, 4, 5} print(set_a | set_b) # Union: {1, 2, 3, 4, 5} print(set_a & set_b) # Intersection: {3} print(set_a - set_b) # Difference: {1, 2}

⚙️ C++ Equivalent

// C++ std::set (ordered) or std::unordered_set #include #include set<int> numbers = {1, 2, 3, 4, 5}; unordered_set letters = {"a", "b", "c", "a"}; // Duplicates removed // Set operations set<int> set_a = {1, 2, 3}; set<int> set_b = {3, 4, 5}; set<int> result; // Union set_union(set_a.begin(), set_a.end(), set_b.begin(), set_b.end(), inserter(result, result.begin())); // Intersection, difference use similar syntax

🎨 Decorators

ADVANCED

What are Decorators?

Functions that modify or enhance other functions without changing their code.

🚗 Car Analogy

Decorator = Car wrap or body kit - changes appearance/features without modifying the engine

Example: Add racing stripes decorator → same car, looks faster!

@turbocharger decorator → add power boost without rebuilding engine

@alarm_system decorator → add security without redesigning the car

def timing_decorator(func): import time def wrapper(*args, **kwargs): start = time.time() result = func(*args, **kwargs) end = time.time() print(f"{func.__name__} took {end-start:.4f} seconds") return result return wrapper # Using decorator with @ syntax @timing_decorator def slow_function(): import time time.sleep(1) return "Done!" slow_function() # Prints: slow_function took 1.0001 seconds

⚙️ C++ Equivalent

C++ doesn't have decorators, but similar patterns exist:

// C++ - Function wrapper or template metaprogramming template<typename Func> auto timing_wrapper(Func func) { return [func](auto... args) { auto start = chrono::high_resolution_clock::now(); auto result = func(args...); auto end = chrono::high_resolution_clock::now(); auto duration = chrono::duration_cast(end - start); cout << "Took " << duration.count() << "ms" << endl; return result; }; } // Usage auto timed_func = timing_wrapper(my_function);

Note: C++ uses RAII, templates, and wrappers for similar effects

Common Built-in Decorators

class MyClass: # Static method - doesn't need instance or class @staticmethod def static_method(): return "No self or cls needed" # Class method - receives class as first argument @classmethod def class_method(cls): return f"Called on class {cls.__name__}" # Property - access method like an attribute @property def my_property(self): return self._value obj = MyClass() print(MyClass.static_method()) print(MyClass.class_method())

⚠️ Exception Handling

CORE CONCEPT

🚗 Car Analogy

try = Attempting to start the car

except = Backup plan if car won't start (dead battery, out of gas)

else = What to do if car starts fine (drive to work!)

finally = Always happens (close garage door regardless)

raise = Sound the alarm! Manual problem notification

try: x = 10 / 0 # This will raise ZeroDivisionError except ZeroDivisionError as e: print(f"Error: {e}") except Exception as e: # Catch all other exceptions print(f"Unexpected error: {e}") else: print("No errors occurred") # Runs if no exception finally: print("This always runs") # Cleanup code # Raising exceptions def validate_age(age): if age < 0: raise ValueError("Age cannot be negative") return age

⚙️ C++ Equivalent

// C++ exception handling try { int x = 10 / 0; // Undefined behavior in C++! } catch (const runtime_error& e) { cout << "Error: " << e.what() << endl; } catch (const exception& e) { // Catch all std exceptions cout << "Unexpected: " << e.what() << endl; } catch (...) { // Catch absolutely everything cout << "Unknown error" << endl; } // C++ doesn't have 'else' - use flag or nest // 'finally' doesn't exist - use RAII or destructors // Throwing exceptions int validate_age(int age) { if (age < 0) { throw invalid_argument("Age cannot be negative"); } return age; }

Key Differences: C++ uses RAII for cleanup instead of finally

Common Exception Types

Exception When it Occurs
ValueError Wrong value type (e.g., int("abc"))
TypeError Wrong type (e.g., "string" + 5)
KeyError Dictionary key doesn't exist
IndexError List index out of range
FileNotFoundError File doesn't exist
ZeroDivisionError Division by zero

📁 File Input/Output

COMMON USE

🚗 Car Analogy

File = Car's logbook/manual stored in glove compartment

Read mode ('r') = Looking at the manual without writing in it

Write mode ('w') = Starting fresh logbook (erases old entries!)

Append mode ('a') = Adding new entries to existing logbook

Close file = Put logbook back in glove compartment properly

Reading Files

# Read entire file with open("data.txt", "r") as file: content = file.read() print(content) # Read line by line with open("data.txt", "r") as file: for line in file: print(line.strip()) # Remove newline chars # Read all lines into list with open("data.txt", "r") as file: lines = file.readlines()

Writing Files

# Write (overwrites existing file) with open("output.txt", "w") as file: file.write("Hello, World!\n") file.write("Second line\n") # Append (adds to existing file) with open("output.txt", "a") as file: file.write("Appended line\n") # File modes: 'r' = read, 'w' = write, 'a' = append, 'r+' = read/write

⚙️ C++ Equivalent

// C++ file I/O using fstream #include #include // Reading entire file ifstream file("data.txt"); string content((istreambuf_iterator<char>(file)), istreambuf_iterator<char>()); file.close(); // Reading line by line ifstream file("data.txt"); string line; while (getline(file, line)) { cout << line << endl; } file.close(); // Writing to file ofstream outfile("output.txt"); // ios::out mode (overwrite) outfile << "Hello, World!\n"; outfile << "Second line\n"; outfile.close(); // Appending to file ofstream appendfile("output.txt", ios::app); appendfile << "Appended line\n"; appendfile.close();

🔒 Context Managers (with statement)

ADVANCED

Context managers ensure resources are properly cleaned up (e.g., files are closed).

🚗 Car Analogy

with statement = Valet parking service - they handle parking AND retrieving your car

You don't worry about finding a spot or remembering where you parked

Guaranteed car retrieval when done, even if restaurant catches fire (exception)!

# The 'with' statement automatically closes resources with open("file.txt") as f: data = f.read() # File is automatically closed here # Creating custom context manager class DatabaseConnection: def __enter__(self): print("Opening connection") return self def __exit__(self, exc_type, exc_val, exc_tb): print("Closing connection") return False # Don't suppress exceptions with DatabaseConnection() as db: print("Using database")

⚙️ C++ Equivalent

// C++ uses RAII (Resource Acquisition Is Initialization) // Destructors automatically called when object goes out of scope class DatabaseConnection { public: DatabaseConnection() { cout << "Opening connection" << endl; } ~DatabaseConnection() { // Destructor - automatic cleanup! cout << "Closing connection" << endl; } }; { DatabaseConnection db; // Constructor called cout << "Using database" << endl; } // Destructor automatically called here! // Or use smart pointers (unique_ptr, shared_ptr) { auto db = make_unique(); // Automatically cleaned up when out of scope }

Philosophy: Python = explicit 'with', C++ = automatic RAII

🔄 Iterators & Generators

ADVANCED

🚗 Car Analogy

Iterator = Assembly line - one car at a time, methodical process

Generator = Made-to-order factory - builds next car only when customer asks (memory efficient!)

yield = "Here's one car, I'll pause production until you need the next one"

vs return list = "Here are ALL 1000 cars at once!" (uses lots of parking lot space/memory)

Iterators

# Any object that implements __iter__() and __next__() class Counter: def __init__(self, max_value): self.max_value = max_value self.current = 0 def __iter__(self): return self def __next__(self): if self.current >= self.max_value: raise StopIteration self.current += 1 return self.current for num in Counter(5): print(num) # 1, 2, 3, 4, 5

Generators (Memory Efficient)

# Generator function (uses yield) def fibonacci(n): a, b = 0, 1 for _ in range(n): yield a # Returns value and pauses a, b = b, a + b for num in fibonacci(10): print(num) # Generator expression (like list comprehension) squares_gen = (x**2 for x in range(1000000)) # Doesn't create list in memory!

⚙️ C++ Equivalent

// C++ Iterators (built into STL containers) vector<int> numbers = {1, 2, 3, 4, 5}; for (auto it = numbers.begin(); it != numbers.end(); ++it) { cout << *it << endl; } // Range-based for loop (syntactic sugar) for (int num : numbers) { cout << num << endl; } // C++20 coroutines (generators!) #include generator<int> fibonacci(int n) { int a = 0, b = 1; for (int i = 0; i < n; ++i) { co_yield a; // Similar to Python yield! auto temp = a; a = b; b = temp + b; } } // Pre-C++20: Use custom iterator classes

💡 Quick Tips for Midterm

Remember These Key Points:

  • self is always the first parameter in instance methods
  • __init__ is the constructor, not the same as __str__ or __repr__
  • Lists are mutable, tuples are immutable
  • Dictionaries use curly braces {}, sets also use {} but no key:value pairs
  • Indentation matters! Python uses indentation for code blocks
  • range(5) gives you 0,1,2,3,4 (not 1,2,3,4,5)
  • try/except/finally - finally always runs, even with return statements
  • with statement automatically handles resource cleanup
  • yield makes a function a generator (memory efficient)
  • Lambda functions are anonymous single-expression functions
