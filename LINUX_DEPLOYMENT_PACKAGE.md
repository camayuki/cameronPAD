## 🚀 Quick Deployment Steps

### Minimum Steps (5 minutes)

```bash
# 1. Transfer files to Linux
scp -r cameronPAD_main2 user@server:/opt/

# 2. SSH to server
ssh user@server

# 3. Run setup
cd /opt/cameronPAD_main2
chmod +x setup_linux.sh
./setup_linux.sh

# 4. Create admin user
source venv/bin/activate
python3 create_admin.py

# 5. Start server
./start.sh
```

Done! Access at `http://server-ip:8000`

### Production Deployment (15 minutes)

Follow **LINUX_DEPLOYMENT.md** for:
- Systemd service (auto-start on boot)
- Nginx reverse proxy (better performance)
- SSL/HTTPS (security)
- Firewall configuration
- Automatic backups

## 🔄 Transfer Methods

### Option 1: Git Clone (Easiest)
```bash
# On Linux server
git clone https://github.com/yourusername/cameronPAD.git
cd cameronPAD
./setup_linux.sh
```

### Option 2: SCP Transfer
```bash
# On Windows (PowerShell)
scp -r D:\Repositories\cameronPAD_main2 user@server:/opt/cameronPAD

# On Linux
cd /opt/cameronPAD
./setup_linux.sh
```

### Option 3: Archive Transfer
```bash
# On Windows
Compress-Archive -Path D:\Repositories\cameronPAD_main2\* -DestinationPath cameronpad.zip

# Transfer cameronpad.zip (SFTP, USB, etc.)

# On Linux
unzip cameronpad.zip -d /opt/cameronPAD
cd /opt/cameronPAD
./setup_linux.sh
```

### Option 4: Rsync (Fast, incremental)
```bash
# On Windows with WSL or on Linux
rsync -avz --progress D:\Repositories\cameronPAD_main2/ user@server:/opt/cameronPAD/
```
